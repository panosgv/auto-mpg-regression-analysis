Abstract
 
This project investigates the predictive modeling of vehicle fuel efficiency, specifically targeting the miles per gallon (MPG) metric, using a classic automotive dataset. The primary objective is to construct, evaluate, and compare a comprehensive suite of regression algorithms to accurately capture the relationship between a vehicle's physical engineering attributes and its resulting fuel consumption. The methodological approach begins with establishing a baseline using standard Linear Regression, followed by Polynomial Regression to model underlying non-linear trajectories between individual features and the target variable.  To systematically address potential multicollinearity among the physical features and to enforce automated feature selection, regularized linear models—specifically Ridge, Lasso, and Elastic Net—will be trained and optimized. Finally, the project will implement advanced, non-linear machine learning architectures by deploying Support Vector Regressors (SVR) and Random Forest ensembles. These advanced models will be evaluated on their capacity to handle complex, multidimensional feature interactions without the need for exhaustive manual feature engineering. The predictive performance of all algorithms will be benchmarked using standardized metrics such as Mean Squared Error (MSE) and the coefficient of determination.

Data Exploration

The selected dataset contains 398 distinct entries, with each instance representing a specific vehicle model produced during the late 20th century. The primary target for the regression tasks is a single continuous variable representing fuel efficiency. To predict this target, the dataset provides 8 explanatory features that span a variety of data types, requiring specific preprocessing steps.  The feature space includes continuous numerical variables representing physical properties (e.g., engine displacement, vehicle weight, and acceleration time) and discrete numerical variables (e.g., number of cylinders and model year). Additionally, there is a nominal categorical variable representing the geographical origin of the vehicle, which will necessitate transformations such as one-hot encoding. An initial quality assessment of the dataset reveals a high degree of completeness, with the exception of a single continuous feature that contains 6 missing values. These instances will be addressed through statistical imputation strategies during the data cleaning phase. The exploratory data analysis (EDA) will primarily focus on visualizing the individual statistical distributions of the continuous features and mapping the pairwise correlations across the dataset. Identifying these correlations is a critical preliminary step, as high collinearity between features (such as engine size and vehicle weight) directly informs the necessity and expected behavior of the regularization techniques planned for the modeling phase. Finally, numerical features will be scaled to ensure stable and efficient convergence for the algorithms that rely on distance calculations.
